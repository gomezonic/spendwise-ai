# SpendWise AI 💰

SpendWise AI is a smart personal finance management application that helps users track their expenses, manage their spending, and get useful insights about their financial habits.

## ✨ Features

- 📊 Track and manage expenses
- 💰 Monitor spending habits
- 🤖 AI-powered financial insights
- 📈 View spending summaries
- 🔐 Simple and secure user experience
- 📱 Responsive interface

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Groq API
